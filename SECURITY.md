# Security

This policy applies to every TypeSOL repository that does not have its own `SECURITY.md`. The compiler's policy,
with what counts and the audit status, is in [typesol/typesol](https://github.com/typesol/typesol/blob/main/SECURITY.md).

## Reporting a vulnerability

Please report privately, not in a public issue: use the **"Report a vulnerability"** button on the affected
repository's Security tab (GitHub private vulnerability reporting). For anything in the compiler, runtime, CLI or
generated clients, report on [typesol/typesol](https://github.com/typesol/typesol/security).

Include what you ran and the steps that show the problem. We aim to acknowledge reports within 3 days.
